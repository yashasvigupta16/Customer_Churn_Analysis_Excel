# 📈Customer churn Analysis Dashboard (Excel)
An interactive Excel dashboard that analyses 7,043 telecom customers to uncover why customers leave, with business 
insights and retention recommendations.



## 🎯Problem Statement
Customer Churn directly hurts recurring revenue, and replacing a lost customer costs more than keeping one.
This project answers:
- Which customer segments churn the most?
- What factors(contract, tenure,services,payment method) drive churn?
- What should the business do to reduce it?

## 📊Key Metrics
| Metric | Value |
| Total Customers | 7,043 |
| Customers Lost | 1,869 |
| Overall Churn Rate | 26.54% |
| Avg Monthly Charges | $64.76 |
| Monthly Revenue | $4,56,117 |
